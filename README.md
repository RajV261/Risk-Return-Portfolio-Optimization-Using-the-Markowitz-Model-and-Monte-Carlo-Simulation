# Risk-Return Portfolio Optimisation Using Markowitz Model & Monte Carlo Simulation

## Overview
Applied quantitative finance techniques to construct an optimised investment portfolio 
using historical S&P 500 data — identifying the ideal asset allocation to maximise 
returns per unit of risk.

## Dataset
- 136,687 rows of historical S&P 500 stock price data
- Multi-asset time series spanning several years

## Methods & Techniques
- **Markowitz Portfolio Theory** — mean-variance optimisation to plot the Efficient Frontier
- **Capital Asset Pricing Model (CAPM)** — calculated expected returns based on systematic risk (Beta)
- **Monte Carlo Simulation** — 1,000+ portfolio simulations to model uncertainty and risk scenarios
- **Risk Metrics** — Sharpe Ratio, Sortino Ratio, Value at Risk (VaR)
- **Geometric Brownian Motion** — modelled stochastic price paths for forward simulation

## Key Outcomes
- Identified the optimal portfolio on the Efficient Frontier maximising the Sharpe Ratio
- Quantified downside risk using VaR and Sortino Ratio across simulated scenarios
- Demonstrated how diversification reduces portfolio volatility without sacrificing returns

Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, SciPy
